# Introduction to Programmable Cryptography

This is an attempt at an introductory lecture notes on programmable cryptography.
It is developed by [0xPARC](https://0xparc.org/).
The source files are written in Latex.
To recompile them, simply compile main.tex with your favorite Latex tool.

## Creating a new release

To compile the latest PDF and create a new release, run:

```
git tag v1.0.0
git push origin v1.0.0
```

replacing `1.0.0` with your desired release number.
